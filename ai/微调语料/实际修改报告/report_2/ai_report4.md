# Cleveland 数据集心脏病风险分析报告

## 一、总体风险概况

本报告基于 Cleveland 数据集 **303 例**患者记录，目标变量为二分类诊断标签（0=无心脏病，1=存在心脏病）[KB-1]。

| 指标 | 数值 | 说明 |
|---|---|---|
| 样本总数 | 303 例 | — |
| 阳性例数 | 139 例 | 存在心脏病 |
| 阴性例数 | 164 例 | 无心脏病 |
| **总体阳性率** | **45.9%** | 139 / 303 |
| 平均年龄 | 54.4 岁 | 范围 29–77 岁 |
| 平均静息血压 | 131.7 mmHg | 阴性组 129.3 mmHg |

**结论：** 该数据集中近一半样本（45.9%）为心脏病阳性，属于阳性比例较高的临床样本集，提示该人群整体心脏风险不容忽视。

**关键发现：**
- 阳性率在 **51–70 岁**区间明显升高，达 **50.8%–58.9%**，为风险集中年龄段。
- 41–50 岁组阳性率仅 30.3%，0–40 岁组为 33.3%，相对较低。
- 71–77 岁组样本仅 6 例，阳性率 16.7%，**样本量过小，不宜据此下结论，后续需要补齐相关年龄段数据**。

## 十二、综合结论

1. **总体风险：** 该数据集心脏病阳性率 45.9%（139/303），阳性比例较高。
2. **年龄与性别：** 51–70 岁为风险集中段（阳性率 50.8%–58.9%）；男性阳性率（55.3%）明显高于女性（25.8%）。
3. **症状特征：** 胸痛类型 4（无症状）阳性率最高（72.9%），且为回归分析中显著正向因素（OR=4.464）。
4. **组间差异：** 阳性组年龄更大、血压与胆固醇更高、最大心率更低（−19.1 bpm）。
5. **模型表现：** 随机森林 ROC-AUC 0.915；集成风险分层 ROC-AUC 0.918；Logistic 回归综合分类最优（MCC 0.715）。
6. **风险分层：** 极高风险档 90 例（29.7%），实际阳性率 92.22%，分层有效。
7. **核心特征：** 地中海贫血、主要血管数、胸痛类型、ST 压低、最大心率为关键风险相关特征。

> **说明：** 本报告所有数据均来自给定结构化结果，未引入外部诊疗结论。HL 检验 p 值缺失（null），无法评估回归模型校准优度；71–77 岁组及层次聚类单点簇样本量过小，相关结论不宜外推。
