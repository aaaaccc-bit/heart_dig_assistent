# 为何当前数据更适合 K-means 聚类

## 一、结论先行

在当前 Cleveland 数据集（303 例，阳性率 45.9%）的无监督分群对比中，**K-means 是唯一给出可解释、非退化分群结果的算法**；而作为对照的单链层次聚类出现了“单点簇”，分群失去实际意义。因此，就本次实验数据而言，K-means 更适合用于无监督分群。

需要强调：这一判断**仅基于本次结构化结果中的分群指标**，不代表对算法优劣的一般性结论，也不构成任何诊疗结论。

## 二、核心证据：两种分群方法的结果对比

| 对比维度 | K-means（数值标准化 + 类别独热） | 单链层次聚类（欧氏距离） |
|---|---|---|
| 选定簇数 | 2 | 2 |
| 轮廓系数 | 0.165177 | 0.425815 |
| ARI（与阳性标签） | **0.272951** | -0.001006 |
| 簇 1 例数 / 阳性率 | 137 例 / **74.45%** | 302 例 / 46.03% |
| 簇 2 例数 / 阳性率 | 166 例 / **22.29%** | **1 例** / 0.0% |

## 三、支持 K-means 更适合的具体理由

### 1. 分群结果非退化，两簇规模均衡

- K-means 得到 **137 例与 166 例**两个簇，规模接近，具备分组分析价值。
- 单链层次聚类得到 **302 例与 1 例**，第二簇仅含 1 个样本，属于典型的“单点簇”，无法形成有意义的群体划分。

### 2. 分群与阳性标签具有可观测的对应关系

- K-means 两簇阳性率分别为 **74.45% 与 22.29%**，簇间阳性率差异明显；ARI 为 **0.272951**，说明分群结构与阳性标签存在一定一致性。
- 单链层次聚类的 ARI 为 **-0.001006**，接近 0，分群与阳性标签基本无关。

### 3. 簇特征画像具有可解释性

K-means 两簇在关键指标上呈现清晰差异：

| 指标 | 簇 1（137 例） | 簇 2（166 例） |
|---|---|---|
| 阳性率 | 74.45% | 22.29% |
| 年龄 | 60.02 岁 | 49.83 岁 |
| 最大心率 | 133.62 bpm | 162.8 bpm |
| ST 压低 | 1.75 | 0.45 |
| 主要血管数 | 1.08 | 0.33 |
| 静息血压 | 136.86 mmHg | 127.42 mmHg |

簇 1 表现为年龄偏大、最大心率偏低、ST 压低与主要血管数偏高的组合，簇 2 则相反，画像方向与全样本组间比较（阳性组年龄 56.6 岁 vs 阴性组 52.6 岁；阳性组最大心率 139.3 bpm vs 阴性组 158.4 bpm）方向一致。

### 4. 数据本身适合基于距离/质心的划分

- 本次 K-means 采用**数值标准化 + 类别独热**的预处理，适配了数据中连续型（年龄、血压、胆固醇、最大心率、ST 压低）与分类型（胸痛类型、地中海贫血、主要血管数等）混合的特征结构 [KB-1]。
- 连续特征分布显示各指标量纲差异较大（如胆固醇最大值 564、ST 压低最大值 6.2），标准化后以质心划分的 K-means 能形成上述均衡两簇。

## 四、需要如实说明的局限

- **轮廓系数并不占优**：K-means 轮廓系数为 **0.165177**，低于单链层次聚类的 0.425815。但后者高轮廓系数来自“302 + 1”的退化结构，不能视为更优分群。
- **簇数选择有限**：候选簇数为 2–6，最终选定 k=2；PCA 前两维解释度为 **0.245323 与 0.138377**，累计解释度有限，二维可视化只能部分反映结构。
- **ARI 属中等偏低水平**：0.272951 表明分群与阳性标签仅部分吻合，K-means 分群不能等同于风险判定。
- 上述结论仅针对本次 303 例 Cleveland 数据，**不外推至其他数据集或临床决策**。
- 上述模型为初版模型，需要进一步优化

## 五、小结

综合“分群非退化、簇规模均衡、簇间阳性率差异可观测、簇画像可解释”四点，当前数据下 K-means 比出现单点簇的单链层次聚类更适合作为无监督分群方法；但其轮廓系数与 ARI 水平有限，应作为探索性分组而非诊断依据。
