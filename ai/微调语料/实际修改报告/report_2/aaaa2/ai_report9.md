# 缺失数据缺口（299/303）的偏差风险与结论边界

## 一、缺口的事实定位

- 结构化结果中，"主要血管数大于 0"这一指标的分母为 **299**，摘要写作 **123 / 299（41.1%）**；而全数据集轨迹数为 **303**。
- 由此可确认：该指标存在 **4 例** 的缺失缺口（303 − 299 = 4），缺口比例为 **4 / 303 ≈ 1.3%**。
- 在本报告所依据的结构化结果中，**明确显示分母变化（299）的只有"主要血管数（ca）"这一项**；阳性率（139/303）、年龄段分层、组间比较、连续特征分布等指标未标注各自分母，**不能据此认定它们不存在缺失**——只是缺失未在该结果中体现。
- **注意**：结构化结果未说明这 4 例缺失的具体原因、缺失机制（完全随机缺失 / 随机缺失 / 非随机缺失），也未说明缺失样本的标签分布。以下偏差分析均基于"缺口存在"这一事实做条件性推断，**无法确定**的部分将明确标注。

## 二、可能带来的偏差

### 1. 分母不一致导致的比率可比性偏差

- "主要血管数大于 0"的 41.1% 是以 **299** 为分母计算的，而阳性率 45.9% 等指标以 **303** 为分母。两者分母不同，**不能直接相减或做比例对比**。
- 若将 41.1% 误当作"303 例中的占比"，会系统性高估或低估该指标在全体样本中的真实比例，具体方向取决于 4 例缺失样本的实际取值（4 例全为 0 则真值约 40.6%，全为 1 则约 41.9%），**当前数据无法确定实际方向**。

### 2. 缺失机制未知带来的选择性偏差

- 若 4 例缺失并非完全随机（例如集中在某一胸痛类型、某一年龄段或某一标签组），则 299 例子样本的构成会偏离 303 例总体，导致"主要血管数大于 0"的比例产生**选择性偏差**。
- 结构化结果未提供缺失样本的特征分布，**无法判断**该偏差是否存在及其大小。

### 3. 对含 ca 的模型结果的传导偏差

- 随机森林分析的自变量包含 **ca**，且特征重要性中 **categorical__ca_0.0** 排名第 2（重要性 0.107677）。这说明 ca 在模型中承担了较高权重。
- 若 ca 存在 4 例缺失，模型在训练/评估时对这 4 例的处理方式（删除、插补或单独编码）会直接影响 ca 相关分裂的质量，进而可能影响 **ROC-AUC 0.915468、PR-AUC 0.909616** 等验证指标的稳定性。
- **无法确定**：结构化结果未披露随机森林对缺失值的具体处理策略，也未提供剔除缺失样本后的敏感性分析，因此不能量化该传导偏差的大小。

### 4. 小样本分组的稳定性偏差

- 缺口虽仅 4 例，但在小样本分组中影响会被放大。例如年龄段"71-77"仅 **6 例**、"0-40"仅 **18 例**；若缺失样本落入此类小组，组内阳性率（16.7%、33.3%）的稳定性会进一步下降。
- **无法确定**缺失样本的年龄分布，故不能确认是否发生此类放大；且现有结果未显示 ca 缺失与年龄分层的交叉关系，此条仅为条件性推断。

## 三、因此不能下的结论

| 不能下的结论 | 原因 |
|---|---|
| "主要血管数大于 0 的比例就是 41.1%（针对全部 303 例）" | 该比例分母为 299，非 303，不能外推到全体样本 |
| "主要血管数大于 0 与心脏病阳性率（45.9%）之间的大小关系成立" | 两者分母不同（299 vs 303），直接比较不成立 |
| "ca 的特征重要性 0.107677 是稳健的" | 未提供缺失处理策略与敏感性分析，无法排除 4 例缺失对重要性排序的影响 |
| "随机森林 ROC-AUC 0.915468 不受缺失影响" | 结构化结果未披露缺失处理方式，不能断言模型指标对 ca 缺失不敏感 |
| "缺失是完全随机的" | 结构化结果未提供缺失机制信息，**无法确定** |
| "各年龄段、各胸痛类型的阳性率不受缺失影响" | 缺失样本的标签与分层归属未知，**无法确定**是否影响分层结果 |
| "其他字段（如 thal、cp、chol）没有缺失" | 结构化结果只对 ca 标明了 299 分母，其余字段的分母未标注，**无法确认其完整性** |

## 四、可以保留的结论边界

- 可以陈述："在 **299 例 ca 非缺失样本**中，主要血管数大于 0 者为 **123 例（41.1%）**。"——这是有分母限定的描述性事实。
- 可以陈述：全数据集阳性率为 **45.9%（139 / 303）**，该指标分母完整，不受 ca 缺口影响。
- 涉及 ca 的任何推断（比例外推、模型重要性解读、与其他指标的比较），均须标注 **"基于 299 例非缺失子样本，存在 4 例缺口，结论待缺失机制确认"**。
