# Cleveland 心脏风险分析报告

> **分母标注规则**：凡由样本计算得到的统计量，跟随 (n=分母)，分层统计量使用该层样本数；超参数、判定阈值、编码值、置信水平等无分母项标注"(参数)"，不伪造分母。

## 一、数据概况

本报告基于 Cleveland 数据集，共纳入 **303 例 (n = 303)** 患者记录，其中阳性（存在心脏病）**139 例 (n = 303)**，阴性 **164 例 (n = 303)**，总体阳性占比为 **45.9% (n = 303)**（139 / 303 例）。

数据集涵盖人口统计学、生理指标、心脏功能与诊断结果四类信息，目标变量为二分类标签（0 = 无心脏病，1 = 存在心脏病，编码值为参数）[KB-1]。特征包括年龄、性别、胸痛类型、静息血压、血清胆固醇、空腹血糖、静息心电图、最大心率、运动诱发心绞痛、ST 段压低、ST 段斜率、主要血管数、铊扫描结果等 13 项 (参数) [KB-1][KB-2]。

## 四、性别与胸痛类型

- 男性阳性占比 **55.3% (n = 303)**，女性阳性占比 **25.8% (n = 303)**，两者相差 **29.5 个百分点 (n = 303)**。
- 胸痛类型 4（无症状）的阳性占比为 **72.9% (n = 303)**；**其他胸痛类型的阳性占比未在结果中提供**，故不作类型间比较。

**要点：** 男性阳性占比高于女性；胸痛类型 4 的占比为 72.9%，但缺少同维度对照。

## 十、小结

1. 总体阳性占比 **45.9% (n = 303)**；男性 **55.3% (n = 303)** 高于女性 **25.8% (n = 303)**。
2. 51–70 岁两段占比 **50.8% (n = 130)**、**58.9% (n = 73)**；胸痛类型 4 占比 **72.9% (n = 303)**，其他类型未提供。
3. 阳性组最大心率 **139.3 bpm (n = 139)** 低于阴性组 **158.4 bpm (n = 164)**，差值 −19.1 bpm (n = 303)。
4. Logistic 回归 cp_4 OR **4.463864 (n = 303)**、oldpeak OR **2.329772 (n = 303)**；HL 检验 p 值缺失（NaN，n = 303）。
5. 随机森林 ROC-AUC **0.915468 (n = 303)**、PR-AUC **0.909616 (n = 303)**；前三位 cp_4.0、ca_0.0、thal_3.0。
6. ca 项分母 **299 (n = 299)**，缺 **4 例 (n = 303，1.3%)**；其他字段缺失情况结果未显示。
