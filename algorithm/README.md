# algorithm —— 统计与图表数据算法

主工作台的所有数字都由这个包计算，**不含任何 Qt / PySide 依赖**，可以单独测试、
单独替换数据源。

## 结构

```
algorithm/
├── __init__.py        公开 API：load_dataset / build_workbench / ALGORITHM_VERSION
├── schema.py          列契约（类型、单位、取值范围、缺失）、年龄段、target 分桶
├── dataset.py         CSV → 类型转换 → 校验 → Dataset（含缺失统计与文件指纹）
├── classification.py  三模型同口径分类评估：阈值表、混淆矩阵、ROC/PR
├── clustering.py       KMeans 分群：k 扫描、轮廓系数、簇画像、PCA 投影
├── stats.py           百分比、安全均值、确定性四舍五入（HALF_UP）
├── features.py        业务口径：阳性定义、性别切片、4 个风险因素谓词
├── feature_insight.py 置换重要性、单变量 AUC、组间差异与相关矩阵
├── aggregations.py    每个图表区块一个聚合函数
├── trend.py           迷你趋势：按年龄段聚合 + min-max 归一化到 0..1
├── models.py          UI 无关的视图模型（dataclass）
├── risk_stratification.py  融合概率 → 风险分档、流转、贡献度与人群画像
├── workbench.py       编排：Dataset → WorkbenchPayload
├── data/              cleveland.csv + 字段说明 + 数据约定
└── tests/             单元测试与黄金测试
```

## 用法

```python
from algorithm import load_dataset, build_workbench

dataset = load_dataset()                 # 默认读取 algorithm/data/cleveland.csv
payload = build_workbench(dataset)       # 一次算完整页

payload.total, payload.positive          # 303, 139
payload.kpis                             # 4 个 KPI（数值、单位、badge、0..1 趋势序列）
payload.age_bands.bands                  # 年龄段柱图数据 + 高亮下标
payload.positivity                       # 环图 + 性别/胸痛类型拆分
payload.target_slices                    # target 分级构成
payload.risk_factors                     # 风险因素条（含每条的分母）
payload.comparisons                      # 阳性组 / 阴性组 / 差值
```

也可以用一行拿到结果：`build_workbench_from_csv()`。

## 口径

| 项目 | 定义 |
|---|---|
| 阳性 | `target > 0`（即 1–4 级） |
| 年龄段 | `0-40`、`41-50`、`51-60`、`61-70`、`71-77`，闭区间 |
| 柱图高亮段 | 样本量 ≥ 30 的分段中阳性率最高者（避免 `71-77` 仅 6 例造成误判） |
| target 分桶 | `0`、`1`、`2-4` |
| 风险因素 | `exang == 1`、`fbs == 1`、`oldpeak > 0`、`ca > 0`，分母为该列有效样本数 |
| 迷你趋势 | 每个年龄段求均值，再做 min-max 归一到 0..1；常数序列取 0.5 |
| 取整 | 统一 HALF_UP，保留 1 位小数（与设计稿一致） |

性别、胸痛类型等切片也在 `positivity` 里给出，供后续文案生成使用。

## 随机森林分析

`run_random_forest()` 是独立于 `build_workbench()` 的预测分析接口，默认使用全部特征。
每个交叉验证训练折内部先以众数填补缺失值，再对分类字段独热编码，最后拟合随机森林，
因此不会用验证折统计量填补训练数据。结果通过“样本分析 → 随机森林分析”页面查看，
与 Logistic 回归页面互不覆盖。

## 风险分层分析

`run_risk_stratification()` 把每个样本按“逻辑回归 + 随机森林”的**折外概率均值**
分到四个档位，供“风险分层”页面使用：

| 档位 | 概率区间 | 当前数据（n=303） |
|---|---|---:|
| 低风险 | `[0, 0.25)` | 115 例（38.0%），实际阳性 13 例（11.3%） |
| 中风险 | `[0.25, 0.50)` | 61 例（20.1%），实际阳性 15 例（24.6%） |
| 高风险 | `[0.50, 0.75)` | 37 例（12.2%），实际阳性 28 例（75.7%） |
| 极高风险 | `[0.75, 1]` | 90 例（29.7%），实际阳性 83 例（92.2%） |

- 阈值是固定的概率切点而不是分位数，档位比例因此是数据算出来的结果，不预设金字塔形状；
- 概率来自 5 折分层交叉验证的折外预测，样本不会被自己参与训练的模型打分；
- 结果同时给出档位到实际诊断的流转、log-odds 分解得到的关键因素贡献占比、
  高危人群 6 项指标占比画像，以及极高风险样本明细；
- 结果对象记录 `dataset_fingerprint`、折数、随机种子和版本，换数据后可复现。

## 分类评估（三模型同口径对比）

`run_classification_evaluation()` 让 Logistic 回归、随机森林和 MLP 共用**同一个
分层 5 折划分**与同一套预处理，在折外概率上计算指标，避免各页面各跑一份数据
导致指标不可比。

默认阈值 0.5 下的结果：

| 模型 | ROC-AUC | PR-AUC | Brier | 准确率 | 敏感度 | 特异度 | F1 | MCC |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Logistic 回归 | 0.9146 | 0.9123 | 0.1137 | 85.8% | 79.9% | 90.9% | 0.838 | 0.715 |
| 随机森林 | 0.9155 | 0.9096 | 0.1207 | 82.8% | 79.1% | 86.0% | 0.809 | 0.654 |
| 神经网络（MLP） | 0.8878 | 0.8791 | 0.1407 | 83.2% | 83.5% | 82.9% | 0.820 | 0.662 |

- 阈值依赖的指标在 0.20–0.80（步长 0.05）上预计算，页面切换阈值不重新拟合；
- 每个模型只保留与其自身页面一致的配置，不在此处调参；
- ROC/PR 曲线点、混淆矩阵四格计数与 MCC 一并返回，供“样本分析 → 分类评估”页使用。

## 特征洞察

`run_feature_insight()` 同时回答两个问题，避免"重要性"只给出一个排名：

- **模型依赖度**：在每一折的验证集上把某一列打乱，重新用该折的随机森林打分，
  AUC 的平均下降即该特征的置换重要性；负值表示打乱后反而更好（无贡献）。
- **单变量判别力**：只用一个特征拟合逻辑回归并做同样的 5 折，得到该特征单独的 AUC。

当前数据上的对照（节选）：

| 特征 | 置换重要性 | 单变量 AUC | 说明 |
|---|---:|---:|---|
| 地中海贫血 | +0.051 | 0.745 | 模型最依赖，单独也最强 |
| 主要血管数 | +0.043 | 0.734 | 两项都靠前 |
| 胸痛类型 | +0.031 | 0.735 | 两项都靠前 |
| 最大心率 | +0.004 | 0.743 | 单独很强但模型几乎不用，信息被 ST 压低/年龄分摊 |
| 静息心电图 | -0.002 | 0.584 | 打乱后 AUC 不降反升，可视为无贡献 |

同时返回连续特征（年龄、静息血压、胆固醇、最大心率、ST 压低）的 Spearman 相关矩阵，
以及阳性组/阴性组的均值、差值和 Cohen's d，供「特征洞察」页的四块图表使用。

## 聚类分析（无监督分群）

`run_clustering()` 不依赖 `target`，只用 13 个特征做聚类，并把 **k=2–6
的整条扫描曲线**一次算完。两种方法可选：

- `method="kmeans"`（默认）：数值标准化 + 类别独热后跑 KMeans；
- `method="single"`：同样的矩阵上跑**最小距离层次聚类（单链，欧氏距离）**。

页面用「最小距离（单链）」切换两种结果。当前数据上的单链结果是典型的**链式效应**：
k=2 时分成 302 例 + 1 例，k=3 起出现多个单点簇，ARI 接近 0。轮廓系数反而高达
0.43（单点簇按定义不贡献簇内距离，虚高了指标），所以结果对象提供
`has_singletons`，页面在出现单点簇时直接给出红色提示，并注明“不能据此判断分群质量”。

| k | 轮廓系数 | CH 指数 | Davies-Bouldin | ARI（与阳性） | 首末簇阳性率 |
|---:|---:|---:|---:|---:|---|
| 2 | 0.165 | 63.1 | 2.14 | 0.273 | 74.5% / 22.3% |
| 3 | 0.126 | 47.8 | 2.28 | 0.230 | 85.4% / 21.5% |
| 4 | 0.120 | 39.5 | 2.27 | 0.163 | 89.5% / 18.5% |
| 5 | 0.107 | 34.3 | 2.36 | 0.154 | 84.6% / 14.9% |
| 6 | 0.093 | 30.3 | 2.43 | 0.153 | 88.5% / 6.5% |

- 预处理（中位数/众数填补、数值标准化、类别独热）在整份数据上拟合：无监督任务
  不存在标签泄漏，同一变换供所有候选 `k` 复用；
- 簇按实际阳性率从高到低编号，`簇 1` 永远是风险最高的一簇；
- 轮廓系数在 k=2 时最高且随 k 单调下降，说明数据只支持粗分；两簇阳性率相差
  50 多个百分点，但簇间仍有重叠，应作为风险分群而不是疾病亚型；
- 结果同时给出 PCA 二维坐标与解释度、每个簇的临床指标均值，供页面画散点与画像表。

## 扩展

- 新增指标：在 `aggregations.py` 加函数，并把结果加进 `models.WorkbenchPayload`。
- 换配色/图标：与本包无关，只改 `ui/`。
- 缓存：数据只有 303 行，单次构建远低于 10 ms，暂不需要；如换大文件，可用
  `dataset.fingerprint` 做键缓存 payload。
